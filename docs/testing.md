# Developer verification

[ADR 0042](decisions/0042-use-fixed-lean-verification-and-explicit-diagnostics.md) defines four owners: fast TypeScript logic/controllers, JVM/JTE/MockMvc/PostgreSQL, minimal native compatibility, and explicit deep diagnostics. Test size (resources and time) is separate from scope (behavior). Important behavior belongs at the lowest effective layer; there is no required numerical test pyramid.

| Intent | Command | Evidence and limits |
|---|---|---|
| Quick TypeScript feedback | In `frontend`: `node node_modules/vitest/vitest.mjs run src/homepage/writing/controllers.test.ts` | Only the requested file; no database or browser |
| Quick JVM feedback | `./gradlew :content-publishing:test --tests 'fully.qualified.ClassName'` | Targeted owner only; app tests may require generated frontend/JTE resources |
| Relevant types or formatting | In `frontend`: `npm run typecheck`, or `node node_modules/prettier/bin/prettier.cjs --check <changed-files>` | Use when relevant; no reinstall per edit |
| Ordinary frontend | In `frontend`: `npm run test:unit` | All fast units/controllers and representative 10+10 scalar/live seeds; default per-test deadline 10 seconds |
| Ordinary repository | `./gradlew check` | Automation, all essential JVM/security, real PostgreSQL integration/migrations and ordinary frontend; no native browser or 100+100 exploration |
| Application / separate CI owners | `./gradlew applicationCheck`, `applicationJvmCheck`, or `frontendCheck` | Application combines JVM and ordinary frontend; split owners preserve the same mandatory coverage |
| CI frontend qualification | `node frontend/scripts/verification/unit-run.mjs` | Independent discovery, exact first attempts/phases and 10+10 seeds; no filters or cached success |
| Ordinary native artifact qualification | `PERSEFONIA_BROWSER_SUITE=native bash scripts/browser/check.sh` | Explicit; checked BootJar staged in `app/build/{ci,libs}`, locked dependencies and installed native prerequisites required; one immutable app/DB, 14 cases |
| Full scalar / live exploration | In `frontend`: `npm run test:physics:scalar` / `npm run test:physics:live` | Explicit 100 seeds in the requested pipeline; never auto-selected |
| Full frontend diagnostics | `./gradlew :app:frontendDeepCheck`, or in `frontend`: `npm run check:full` | Explicit 100+100; not part of `check` |
| Selected native diagnostics | `PERSEFONIA_BROWSER_SUITE=diagnostics bash scripts/browser/check.sh --project desktop-1440 homepage/film/gpu-delivery.spec.ts` | Only retained unique native experiments; never produces ordinary receipts |
| Authenticated browser-focus diagnostics | After own-workspace JVM compilation: `./gradlew :app:writeAdminPreviewClasspath`, then `PERSEFONIA_BROWSER_SUITE=admin PERSEFONIA_BROWSER_PORT=18081 bash scripts/browser/check.sh --project admin-desktop` | Explicit local operation, isolated preview classes/DB; no production test authentication or imported test classpath; forbidden in ordinary CI |

`frontend/scripts/verification/selection-policy.json` is the only mandatory native identity manifest. It contains Chromium desktop 6, Chromium touch 2, Firefox 3 and WebKit 3 file/title/project identities. All four contexts are required on every PR. Unknown, renamed and deleted source also gets the whole ordinary contract. Changed paths remain provenance; they never add deep tests or suppress mandatory tests. Native test deadlines are 20 seconds, total execution 210 seconds, with one worker, isolated contexts and zero retries. Only explicit diagnostics may carry longer scenario deadlines. No nightly workflow runs them.

The native producer performs one separate source discovery and one execution against the candidate. Gate downloads the raw reports and four engine/context receipts, independently normalizes both reports, compares exact source manifest identities, and verifies source/tree/policy/run/attempt/candidate plus first results. It then emits browser acceptance and final qualification. Gate uses Python and Node built-ins, with no npm install or browser provisioning. Verify and Gate always evaluate; failures, cancellation and missing evidence fail closed. Delivery validates trusted master qualification bound to the exact run/attempt and the same immutable candidate. Java 21, OCI provenance, AMD64/ARM64 and RC checks remain in their existing owners.

The native job hard cap is 8 minutes including cold setup; its lifecycle step is capped at 6 minutes and unit execution at 5 minutes. Native 4–5 minutes and PR Gate 10–12 minutes are engineering targets, excluding runner queues, not measured results. Deadline exhaustion fails qualification and preserves the original failure and bounded diagnostics. Media tools remain installed where tests or environment identity still consume them.

Gradle no longer fingerprints the entire repository for every JVM Test task. Tests track their compiled inputs and local source; app architecture/template tests additionally track the cross-module Java, frontend and ADR inputs they read. Build/compilation/Vite outputs can remain incremental; local dependencies reuse their locked input/output fingerprints. CI disables test up-to-date/cache success; witnesses bind the production bytes used by actual JVM execution. Typecheck owns source, tools and browser tests; Vite owns production resources and build configuration. Do not use `clean` or reinstall npm dependencies for each edit.

Migration: `check`, `applicationCheck` and `frontendCheck` now mean ordinary verification; use the explicit deep commands for the former exhaustive physics semantics. `./gradlew :app:browserCheck` remains an explicit compatibility entry: it builds and checksum-stages its own local candidate before the same native lifecycle. It is never a `check` dependency. `playwright.config.ts` forwards to the single native config; legacy cross-browser/comprehensive profile commands and risk routing are retired. `CI_QUALIFICATION_REUSE` remains shadow by default. This policy migration invalidates old receipts and does not enable enforcement or suppress master CI.
