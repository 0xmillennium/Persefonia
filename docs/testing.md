# Test commands and qualification ownership

Run frontend commands from `frontend/`. Use installed locked dependencies. Commands below never imply deployment or remote workflow execution. Costs are unmeasured unless stated. A Node test can be expensive; the complete physics pipelines are exploratory work.

| Purpose | Explicit command | Scope / cost |
|---|---|---|
| One TS owner | `node node_modules/vitest/vitest.mjs run src/homepage/writing/entrance.test.ts` | No npm install, Vite, Spring, DB or browser; normally small, unmeasured |
| One JVM owner | `./gradlew :content-publishing:test --tests 'fully.qualified.ClassName'` from root | Gradle inputs apply; app tests genuinely depend on generated resources |
| Controller + receipt feedback | `node node_modules/vitest/vitest.mjs run src/homepage/presentation.test.ts src/homepage/footer/controller.test.ts scripts/verification/browser-contract.test.ts scripts/verification/unit-contract.test.ts` | Focused; does not establish full CI qualification |
| Ordinary frontend corpus | `npm run test:unit:ordinary` | All unit files, reviewed physics seeds; no native browser; may include runner contract subprocesses |
| Mandatory CI frontend | `node scripts/verification/unit-run.mjs` | Independent discovery, exact first attempts/phases, risk-selected ordinary/full physics; rejects filters |
| Comprehensive frontend | `npm run check:full` | Formatting/types/boundaries/generated media, all units and both 100-seed pipelines, Vite; potentially expensive |
| Full scalar / live separately | `npm run test:physics:scalar` / `npm run test:physics:live` | Each runs its original full 100 seeds; no automatic nightly schedule |
| Ordinary native artifact qualification | `PERSEFONIA_BROWSER_SUITE=native bash scripts/browser/check.sh` from root | Requires checked BootJar staged in `app/build/{ci,libs}`, locked dependencies and native prerequisites; one disposable DB/app, four logical contexts, plus risk-required native profiles; expensive, hosted ordinary authority |
| Required admin native | `./gradlew :app:writeAdminPreviewClasspath` after the owning JVM build, then `PERSEFONIA_BROWSER_SUITE=admin PERSEFONIA_BROWSER_PORT=18081 bash scripts/browser/check.sh` from root | Own-workspace compiled main/JTE/preview classes and tested dependencies required; a separate disposable DB/app, two Chromium cases, fresh namespaced synthetic accounts; no production test auth or imported test outputs |
| Comprehensive legacy native | `npm run test:browser:comprehensive` / `npm run test:browser:cross:comprehensive` | Explicit broad diagnostic suites; expensive/unmeasured; never automatic alongside ordinary CI |
| Deep native media / journeys | `npm run test:native:media` / `npm run test:native:journeys` | Additional cases against an already running isolated fixture; ordinary overlap is excluded; not complete admission receipts by themselves |
| Legacy mutable content variants | `PERSEFONIA_BROWSER_SUITE=chromium bash scripts/browser/check.sh --project desktop-1440 public/homepage.spec.ts` from root without `CI` or receipt opt-in | Separate disposable fixture; never cohost with immutable native qualification; unmeasured |
| Comprehensive repository | `./gradlew check` from root | Automation, domain/JVM, real DB integration/migration, comprehensive frontend including both full physics paths; native browsers remain separately explicit |

`CI / Verify` and `CI / Gate` remain stable. Ordinary CI consists of Automation, independent Build/JVM and Frontend, the actual BootJar consumer native job, independent browser receipt reconciliation, Verify and Gate. Delivery requires the exact hosted job inventory, current policy-bound evidence, authoritative master candidate and Java 21. Native AMD64/ARM64 OCI qualification and RC environment protection remain separate unchanged obligations.

The source policy is `frontend/scripts/verification/selection-policy.json`. Native ordinary cases have exact file/title/project identities and zero expected skips. Chromium desktop and touch, Firefox and WebKit execute sequentially with one worker and no retries. All cases get fresh Playwright contexts. Deep media/graphics and long journeys remain directly callable; only source-owned media/physics risk rules make their corresponding deep families mandatory. Writing/CSS and CI-policy changes do not expand to every deep family. Unknown or truncated paths block with an actionable classification error. Deleted/renamed/type-changed paths require exact reviewed `classifiedChanges` entries; rename risks include both old and new owners. Changed admin/shared-focus owners require two real admin validation/focus and OWNER/CSRF cases in Build + JVM, after its own tests and Java 21 check. Only three explicit preview classes enter the isolated fixture JAR; other test classes/resources are excluded. CI refuses stale/filtered/foreign-workspace runtimes and missing admin receipts. The public artifact job cannot substitute for this profile; production authentication is unchanged.

CI tests always execute. Local JVM `test` output reuse fingerprints source-reading inputs and classpath; real DB suites remain fresh. Gradle npm input identity hashes effective npm configuration, runtime and relevant environment without exposing values, then fingerprints installed outputs. Vite tracks source, delivery/media manifests, plugins, lock/config/runtime and generated outputs. No test receipt is inferred from an up-to-date build, cached XML or a dependency stamp. Automation retains its always-run safeguards.

For a separately authorized hosted pilot, run the new inventory once. Measure npm/media/browser setup, DB/app lifetime, per-engine/context execution, Build/JVM and Frontend durations, critical path, Verify/Gate latency, runner-minutes and first failures. Confirm triggered physics/media and conditional admin execution and admission. Do not run the retired eight-job matrix in parallel. A 10–12 minute Gate remains a target; a two-job split requires a separate measured decision. Reuse stays shadow; this policy change requires full new-policy master qualification.
