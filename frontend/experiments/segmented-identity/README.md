# Segmented 0x identity

An isolated eight-fragment identity primitive. The production homepage does not load it. No application backend, client framework, or additional runtime dependency is required.

## Engineering target

The target is a qualified decorative browser interaction for this approved eight-piece mark. Correctness means finite, contained rigid bodies, exact visual/collider alignment, bounded work/storage, passive contact responses, validated group releases and safe rearming. Maintainability means independently testable geometry, physics, permission policy, forecasting, input, scheduling and rendering responsibilities; the renderer receives only read-only poses, navigator state and optional anchors. A general-purpose game engine or formal standards certification is outside this scope.

Fixed timesteps and substeps follow established rigid-body practice ([Box2D guidance](https://box2d.org/documentation/hello.html)). Static semantic content, keyboard controls, Pause and reduced-motion behavior follow the relevant [W3C animation guidance](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html). These scoped checks do not constitute a full WCAG conformance audit of the website.

For a 60 Hz desktop, the performance goal is animation callback costs comfortably below the 16.7 ms frame interval during ordinary interaction, with no scheduled work at idle. The 10 ms scheduling budget is checked between ticks; the existing 150 ms cross-browser CI ceiling catches large regressions and does not prove this goal. Measure callback percentiles separately without competing stress workers; costs vary with hardware, browser, workload and diagnostics. Callback timings exclude layout/paint/GPU work and must not be presented as delivered frame rate.

Input responsiveness is a separate requirement: the latest retained observation must reach the navigator in the next eligible live tick, with no distance-limited replay tail. Fresh input from idle is consumed on the first animation frame. Actual wall/contact constraints can displace the navigator from an impossible target; ordinary unobstructed fast strokes must still meet the explicit input-to-DOM browser checks below. Callback cost and eventual recovery alone do not qualify responsiveness.

From `frontend/`:

```sh
npm ci
npm run identity:dev
```

Open `http://127.0.0.1:4178/`. Mouse and hovering pen input move a strict circular navigator. Touch and reduced-motion presentations retain the static semantic SVG. Reset, Pause and anchor diagnostics are native keyboard-operable controls. The renderer uses the exact simulation pose without interpolation; scheduling is tested at 60, 90, 120 and 144 Hz. Visual interpolation must never silently change collider geometry.

## Geometry and ordinary physics

`geometry.json` contains the approved shared cubic boundaries and rigid home translations. The single symbol has four concave corner wedges, two convex caps and two convex flanks, each with three designed corners. The surrounding negative space reads as 0; straight 57° diagonal channels through the core read as x, with a 15.5-unit width. Setting all source translations to zero closes the same pieces into a 116 × 160 rectangle. This is the final shared-curve design approved on 2026-10-10.

`geometry.ts` flattens each shared cubic once with a maximum curve-to-chord error of 0.12 stage units, then reuses those vertices by reflection. Rendering and collision detection use identical polygon contours, including the concave corners; no independent visual/collider curves are fitted. `geometry-loader.ts` derives area centroids, uniform-density mass/inertia, three contour-corner anchors and convex decompositions. `generate-static.mjs` produces the coupled no-JavaScript HTML/SVG; `identity:build` rejects stale generated files. Run `identity:geometry` intentionally after changing geometry, then rerun every qualification command.

The loader rejects self-intersections, repeated/backtracking edges, invalid coordinates, degenerate anchors and invalid mass properties before decomposition, and normalizes clockwise contours without changing their world anchors. IDs cannot contain pair/cluster delimiters; the core rejects duplicate identities and invalid stage dimensions or mass/inertia. Fixtures validate completely before mutating the world; invalid pointer intervals leave state untouched.

`core.ts` advances deterministic 1/120-second ticks with four internal subdivisions for live input. Coordinates are SVG stage units in a 960 × 620 stage; linear velocity is units/second, angle is radians, and angular velocity is radians/second. Mass is polygon area/3500. Each anchor contributes a home spring with total stiffness 12/second². Linear/angular damping use exponential decay at 3.2/3.6 per second. Contact impulses include angular lever arms, restitution 0.08 and position-only geometric projection. Ghosted fragment pairs skip both impulse and projection; navigator and wall constraints remain active.

In the final two solver passes, concave solid contacts still deeper than the 0.3-unit tolerance use whole-compound position separation. SAT translation intervals for all convex subpart pairs are combined; the smallest separating displacement among the contact normal, its opposite and four cardinal directions is selected. Candidates that worsen wall or navigator penetration are avoided when possible; if all are constrained, the smallest separating candidate remains subject to the ordinary boundary/navigator passes. This bounded correction changes positions only, not velocities, impulses or permissions. It is not a global minimum-translation or multi-body packing solver. Shallow contacts and the first eight passes retain the existing projection.

Each subpart interval stops testing axes as soon as its entry exceeds its exit: intersecting additional constraints cannot restore an empty interval. Every subpart pair and candidate direction remains part of the separation calculation.

If the final state still has a solid overlap above 0.3 units, up to twenty additional compound/contact passes repair residual multi-body violations before the permission observation, exiting as soon as the state is valid. Coupled curved contacts during renewed interaction can need more correction than the ten ordinary passes. These passes correct only overlaps above that tolerance; polishing already acceptable shallow contacts can otherwise undo a concave pair's repair and perpetuate oscillation. They add no integration time or extra force and never grant exemptions. Live and shadow simulations use the same guard. Already valid states receive no extra correction; the iteration cap still does not guarantee arbitrary packing will converge.

SAT axes and self-projections are cached lazily by immutable world-contour array, preserving early separation exits. Every new pose creates new arrays; caches use weak keys, without rounded pose matching or retained old geometry. Reusing these calculations across opposing convex subparts keeps the curved geometry practical without changing contact arithmetic.

Cached axis-aligned bounds also reject distant navigator contacts and skip wall scans for fully contained bodies. These are conservative broad-phase shortcuts; touching bounds still run the original exact contour/impulse calculations.

Each pose transforms unique contour points once, and convex parts reuse those exact world points. A weak geometry-index cache derives this relationship once; independently authored parts without shared point identities keep their own transforms. World contours/parts are exposed read-only. Bounds use one pass without temporary coordinate arrays, and canonical pair keys avoid per-call sorting arrays.

Navigator momentum transfer saturates smoothly as `720 * tanh(observedSpeed / 720)`. Sampled fixture sweeps retain intervals of at most two stage units; longer live input legs use the contour casts described below. A demonstrated free half-turn equilibrium needs a small additional home torque: it acts only within 0.01 radians of an inverted orientation, with peak acceleration 0.024 radians/second² and quadratic falloff. This deterministic restoring term is shared by live and forecast home forces. Ordinary orientations receive no additional torque.

## Deadlock detection and release

`deadlock.ts` receives read-only observations, never mutable bodies. Actual contact edges form connected groups; existing return relationships keep a cohort together if another piece joins its jam. Merely nearby outsiders remain solid. Actual navigator contact immediately vetoes new releases for its entire physically connected/latched group.

The detector compares observed internal home work against an inexpensive estimate of unconstrained home work over 50 ms. The estimate uses distributed-anchor gradients, velocity, angular velocity, spring acceleration, separate linear/angular damping and the curvature of the home objective. Common translation is removed; rotational and relative positional errors remain. At least one member must have anchor error above one unit and a nonzero home request. Observed work below 25% of a positive free estimate for three consecutive ticks (25 ms) nominates a group. This avoids waiting for absolute speed to become small and avoids treating natural deceleration as proof of a jam. The estimate is a local approximation used only for nomination, never release authority. Scalar-only diagnostic callers without a work estimate retain a conservative kinetic gate.

`forecast.ts` compares exactly two plans from the same frozen world: the current solid baseline and a permission for every internal solid pair of the nominated cohort. Each plan runs six exact ticks (50 ms). A baseline already recovering by 1% of the internal response scale needs no release; the cohort must improve on it by at least 1% of that scale. There is no combinatorial subset search, residual-component ranking or one-second recovery projection.

Before committing, both plans run again from current poses, velocities, navigator and permissions. A successful uninterrupted decision therefore uses at most 24 shadow ticks, including fresh validation. Freshness checks group membership, latches, wall contact, age (400 ms), relative pose/velocity drift and nearby influencing bodies during final validation. Pose limits are three units/0.08 radians; velocity limits are 30 units/second and 0.8 radians/second. Remote pointer movement does not invalidate an unrelated island; nearby movement and entire retained swept paths can. Disconnected islands receive turns in key order with a rotating cursor. Negative assessments are retried after 200 ms; unchanged certified diagnostic jams with releases disabled reuse their assessment instead of continuously resimulating.

The full cohort commits atomically only with a physical solid touch persisting for at least 25 ms. Every sampled shadow tick checks finite/contained state, passive energy channels, strict navigator clearance and all still-solid pair overlaps against the live 0.3-unit tolerance. Permission changes modify no force, pose, velocity or impulse. Every internal cohort relationship becomes `GHOSTED_LATCHED`, including pairs that might meet later during return. Walls, navigator and pieces outside the cohort retain their existing collision response.

During an uninterrupted return, a cohort rearms atomically after every member has anchor error at most one unit, speed below three units/second and angular speed below 0.12 radians/second, and every internal pair has zero overlap and a gap of at least 0.65 units for eight consecutive ticks. Early separation alone cannot cause another internal jam halfway home. Renewed navigator contact with the cohort, including through solid neighbours, interrupts this automatic return: each pair then regains collisions independently after eight consecutive ticks with zero overlap and at least 0.65 units of clearance, regardless of home error or motion. Mouse departure does not resume the interrupted privilege. Still-overlapping pairs remain latched, and new exemptions still require the complete nomination/forecast/validation procedure. Shadows use the same rearm policy and preserve interrupted state. The 25-second return-failure deadline restarts during navigator contact. A failure during an uninterrupted return produces a diagnostic failure, never an unsafe timeout rearm. These checks qualify a bounded decorative interaction; they do not prove global convergence or predict future user input.

## Input, scheduling and lifetime

`input.ts` retains timestamped pointer/coalesced observations. An unidentified device is accepted only for trusted primary, zero-pressure, point-sized hover; known touch and unidentified contact remain static. A trusted hover mouse fallback handles bridges that omit pointer movement after touch. Compatibility-event matching allows integer rounding on each coordinate independently. Matching pointer observations and touch-generated mouse events are suppressed; touch input clears the navigator. `pointer-path.ts` preserves corners and reversals and merges redundant straight samples. The next live tick drains the whole observation batch through `stepStroke`; motion is never replayed over later frames. Leaving, cancelling, blurring or suspending clears pending motion.

Cancellation followed by re-entry in the same frame retains an initial inactive marker. The new stroke establishes presence at its first fresh observation, so there is no strike across the cancelled gap. Cancellation inside an otherwise active batch is rejected atomically; the input adapter clears preceding motion when it receives cancellation.

The queue holds at most 128 observations. On overflow it removes the interior point with least additional path length, carries its duration forward and counts the dropped sample. Endpoints remain; geometry can be approximated under sustained overflow. Telemetry exposes the discarded-observation count. The queue bounds the current input batch, not its replay speed.

`pointer-stroke.ts` divides that batch by arc length while retaining every stored corner/reversal and its original observed speed. Live body integration uses the existing four subdivisions per fixed tick, regardless of stroke distance. Legs longer than two units use a linear circle cast against the actual polygon's finite edges and rounded vertex offsets, including concave cavities. Every crossed body receives the existing saturated momentum response at its first entry into that leg; fast strokes do not geometrically drag a body across their entire distance. The ordinary positional/impulse solver still resolves the navigator at each subdivision endpoint and constrains impossible wall squeezes. Short legs retain local positional response. All retained path points participate in forecast relevance, including excursions whose endpoints coincide. These casts query each current body pose; they are not general continuous collision detection for rotating or mutually moving bodies. See [Box2D's collision-query documentation](https://box2d.org/documentation/md_collision.html) for the distinction between shape casts and full time-of-impact solving.

`scheduler.ts` permits at most two live ticks and four shadow ticks per rendered frame, with at most two shadow ticks per live tick, and checks a 10 ms work budget between ticks. A newly awakened pointer gets one fixed tick on the first animation frame, without changing subsequent 120 Hz scheduling. This permits the widest supported forecast to finish before its age limit at 60 Hz. Delayed wall-clock time is discarded instead of inflating physics dt. An individual tick cannot be preempted, so this is a scheduling policy rather than a hard frame-time guarantee. Raw deterministic scalar `stepFixed` calls retain unrestricted sampled sweep replay for historical regression fixtures; browser input uses the explicit bounded `stepStroke` batch contract and its own seeded regression suite.

Idle, paused, hidden and reduced-motion states stop scheduling. Persisted `pagehide` suspends resources; `pageshow` resumes the cached document. Final teardown disposes listeners and renderer nodes. Anchor nodes are reused, unchanged SVG attributes are not rewritten, and status text changes only with state. Full snapshots are materialized only when telemetry is open: live refresh is at most once per 200 ms, with immediate refresh for explicit controls/opening and the transition to REST. Telemetry adds no timers or animation frames. Event history retains the latest 512 transitions plus a cumulative count; headless diagnostic callers may explicitly request `eventHistoryLimit: Infinity` for complete replay logs.

## Qualification

```sh
npm run identity:check
npx playwright install --with-deps --no-shell chromium firefox webkit
npm run identity:browser
npm run identity:browser:built
```

`identity:check` typechecks implementation, configs and tests, runs all deterministic tests including 100 sampled stress seeds, 100 live batched stress seeds and retained failing-seed fixtures, and checks/builds static assets. The browser suite runs all acceptance/hardening checks in Chromium, Firefox and WebKit, plus 100 Chromium stress seeds. Native 860-unit strokes in empty space and through the logo must arrive in one navigator update within a 75 ms CI allowance; coalesced reversals must reach their latest endpoint on the first awake frame. These input-to-DOM checks are distinct from the 150 ms callback-cost ceiling and do not measure paint/GPU latency. CDP pen-bridge qualification is Chromium-specific. The release suite rebuilds on port 4179 and verifies CSP, exclusion of the development test API, fast native input and actual persisted-history restoration. CI runs these gates separately from the production homepage checks.

If port 4178 already serves this experiment, opt into reusing it with `IDENTITY_REUSE_SERVER=1 npm run identity:browser`. Reuse is disabled by default. Headless manual inspection is available only in Vite development with `/?test=1`; the test API is removed from release builds.

For separate runtime measurement, leave `identity:dev` running and execute `node experiments/segmented-identity/profile-runtime.mjs chromium` (or `firefox` / `webkit`) after qualification workers finish. Three repeated scripted interactions measure callback p50/p95/max with diagnostics closed and open; raw samples and browser version are written to ignored `test-results/segmented-identity/profile/`. `IDENTITY_PROFILE_URL` can select a running release preview. This is a repeatable diagnostic workload, not a cross-device benchmark or a GPU profiler.

Tests check finite/contained state, navigator penetration ≤0.02 units, solid fragment penetration ≤0.3 units during motion, passive kinetic-energy changes, zero permission-energy injection, safe separation/rearm and eventual tight REST. REST requires anchor error <0.002, linear speed <0.002, angular speed <0.0001, overlap <0.0001 and no ghosted pair. Initial fixtures may overlap; invariants apply after every tick. The kinetic ledger does not claim total mechanical-energy conservation: position projection can change spring potential.

Generated test results/screenshots belong under ignored `frontend/test-results/`, not beside source. Retained JSON fixtures are executable regression inputs, not historical reports. `tests/legacy-geometry.json` preserves the original nine-fragment contours and anchors for the captured deadlock regressions; fresh stress seeds and browser acceptance use the current eight-fragment design. The small SAT solver has no warm-started contact manifold or general body continuous collision detection. Its qualification envelope is this fixed decorative interaction; arbitrary rigid-body stacks and unbounded geometries are outside that envelope.
